# 소유권 가이드

러스트의 소유권 규칙을 한국어로 정리한 문서입니다. 자세한 내용은 [공식 문서](https://doc.rust-lang.org/book/ch04-00-understanding-ownership.html)를 참고하세요.

## 소유권이란?

모든 값에는 **소유자**가 하나 있습니다. `String` 값은 힙에 저장됩니다.

### 이동(move)

```rust
let s1 = String::from("안녕");
let s2 = s1; // s1 은 더 이상 유효하지 않음
```

### 복사와 클론

`clone()` 으로 깊은 복사를 합니다. 참고: [대여](#대여와-참조).

## 대여와 참조

참조(`&T`)는 소유권을 가져가지 않습니다.

### 가변 참조

한 번에 하나의 `&mut T` 만 허용됩니다.
