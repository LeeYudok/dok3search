# dok3search

로컬에서 시험하는 문서 검색 홈입니다. 카테고리, 최근 문서, 검색, 문서 미리보기에 샘플 데이터를 사용합니다.

```sh
npm ci
npm run dev
```

Vite가 출력하는 로컬 주소를 엽니다. `npm run build`로 TypeScript 검사와 정적 빌드를 실행합니다.

설계 문서 샘플은 [설계 저장소](https://github.com/LeeYudok/dok3search-design)에서 가져왔습니다. [샘플 라이선스](src/samples/design/LICENSE)를 함께 둡니다.
