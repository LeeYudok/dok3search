# Rust Compiler Error E0664

## Summary

#### Note: this error code is no longer emitted by the compiler.

## Explanation

A clobber was surrounded by braces in the `llvm_asm` macro.

Erroneous code example:

```rust
llvm_asm!("mov $$0x200, %eax"
          :
          :
          : "{eax}"
         );
```
