# Rust Compiler Error E0662

## Summary

#### Note: this error code is no longer emitted by the compiler.

## Explanation

An invalid input operand constraint was passed to the `llvm_asm` macro
(third line).

Erroneous code example:

```rust
llvm_asm!("xor %eax, %eax"
          :
          : "=test"("a")
         );
```
