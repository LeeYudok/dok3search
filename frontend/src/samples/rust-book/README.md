# The Rust Programming Language

This is an offline Markdown conversion of the English Rust Book by Steve Klabnik,
Carol Nichols, and Chris Krycho, with contributions from the Rust Community.

The source is the `rust-docs` component distributed with the Rust 1.100.0 toolchain.
`provenance.json` records the exact toolchain and the SHA-256 of the installed
HTML inputs. The source repository is [rust-lang/book](https://github.com/rust-lang/book).
The matching published edition is available at [doc.rust-lang.org](https://doc.rust-lang.org/1.100.0/book/).

One Markdown file represents each page in the original table of contents.
Links among the included pages and the original figures use relative paths.
References to material outside the Book retain their online destinations.
Examples retain their code, including any lines the source hides on screen.
The conversion retains fenced code languages and adds text annotations for
examples whose HTML metadata indicates they fail to compile, panic, or are not run.
Interactive Playground controls, navigation chrome, and styles are omitted.

and `LICENSE-APACHE`. Upstream makes the Book available under either the MIT
