# Codex CLI 0.171.0 업데이트 정리: GPT-6.2 Sol, TUI workspace, 원격 실행

Codex CLI 0.171.0에서 가장 큰 변화는 무엇일까요? 2026년 11월 20일 공개된 이번 버전은 새 모델 두 개를 앞세웠습니다. 그런데 정작 무게중심은 오래 켜 두고 여러 세션을 오가는 사용을 매끄럽게 만드는 데 있습니다. 그 근거는 체인지로그에 그대로 적혀 있죠.

새 기능 6건, 버그 수정 6건, 정비 2건입니다. 숫자만 보면 새 기능이 앞서죠. 다만 실사용에서 크게 와닿는 항목은 세션과 승인 쪽에 몰려 있습니다. 분류별 건수와 대표 항목은 아래 표에 묶었습니다.

| 구분 | 건수 | 대표 항목 |
| --- | --- | --- |
| 새 기능 | 6건 | GPT-6.2 Sol·Astra, TUI workspace 기본 활성화, 원격 실행 |
| 버그 수정 | 6건 | 초안 유지, 권한 프로필 유지, 승인 취소 방지 |
| 정비 | 2건 | Rust 1.99.1, XML 의존성 정리 |

## GPT-6.2 Sol이 기본 모델 선택이 됐습니다

모델 카탈로그에 GPT-6.2 Sol과 GPT-6.2 Astra가 새로 들어왔고, 그중 Sol이 기본 선택 자리를 가져갔습니다. 새로 설치하면 모델 목록에서 두 모델을 바로 만나게 되죠. 기본값이 바뀌었다는 건 처음 Codex를 켠 사람의 첫 선택이 Sol로 정해진다는 뜻입니다. 다만 접근 권한은 계정과 플랜에 따라 갈립니다. 목록에 Sol이 보이지 않는다면 이 판단도 달라지니, 설정 화면에서 한 번 확인해 두는 편이 안전합니다.

## TUI workspace가 기본으로 켜졌습니다

0.171.0부터 TUI workspace가 기본값으로 켜집니다. 메인 대화 옆에서 문서를 검색하고 미리 볼 수 있고, 이미지 미리보기와 서브에이전트 트랜스크립트도 같은 작업공간에서 확인하게 됩니다. 코드를 고치고, 문서를 확인하고, 실행 기록을 보는 일이 한 화면으로 모이니 터미널과 브라우저를 오가던 왕복이 그만큼 줄어들죠. 물론 대화형 TUI 대신 IDE 확장만 쓴다면 체감은 작습니다. 이번 체인지로그에 IDE 통합 항목은 따로 없더군요.

## 세션을 넘겨도 초안과 승인이 남습니다

세션을 바꾸거나 이어 붙여도 작성하던 초안은 원래 스레드에 그대로 남고, 대기 중이던 후속 입력과 끊긴 입력도 사라지지 않습니다. 권한 프로필은 작업 디렉터리를 옮겨도 유지되고, 이전 턴이 늦게 끝나면서 새 턴의 승인을 취소하던 문제도 고쳤죠. 비-Vim 프롬프트 작성기에서는 undo와 redo 단축키를 직접 정할 수 있으며, 첨부 파일과 큰 붙여넣기도 복원됩니다. 하나씩 보면 작은 수정이지만, 모두 작업이 뚝 끊기던 자리를 겨냥합니다.

## 원격 실행과 statusline으로 자동화 범위가 넓어졌습니다

`codex exec --remote <ADDR>` 명령이 추가됐습니다. 이미 떠 있는 앱 서버에서 비대화형 세션을 시작하거나 다시 이어갈 수 있죠. TUI에서는 `/rc`와 `/remote`로 원격 제어를 관리하고, 기기 페어링 코드도 여기서 확인합니다. `/statusline`은 `tui_extensions_statusline`이 켜져 있을 때만 쓸 수 있습니다. 사용자 지정 MCP 상태줄을 고르거나 직접 작성할 수 있죠. 서버 자동화나 원격 개발, 상태 모니터링을 붙이기가 한결 수월해졌습니다.

## 고친 버그는 매일 쓰던 화면에서 나온 것들입니다

수정 목록 여섯 건은 대부분 눈에 보이는 자리에서 나왔습니다. 스크롤을 내리다 이상한 문자가 찍히던 문제와 프롬프트 작성기의 캐럿이 튀던 문제가 사라졌죠. 낡은 터미널 크기로 화면을 다시 그리던 문제도 정리됐습니다. 활성 턴을 조정할 때 이전 편집이 aggregate diff에서 사라지던 문제도 손봤고요. 엔터프라이즈 MCP 로그인은 refresh token 없이 ID token만 발급하는 IdP까지 지원합니다. 조직 환경이라면 특히 반가운 변화입니다.

## 정리: 지금 올려도 될까

정리하면, 새 모델보다 오래 쓰는 흐름을 다듬은 릴리스입니다. 매일 Codex CLI를 켜 두는 사람이라면 TUI workspace와 세션 복원에서 차이를 먼저 느낄 겁니다. 업데이트는 `npm install -g @openai/codex` 명령 하나면 됩니다. 설치 후에는 두 가지만 확인해 보세요. `codex --version`에 0.171.0이 찍히는지, 모델 목록에 GPT-6.2 Sol이 보이는지입니다.
