# Rust 강의 로드맵 — 무엇을 어떤 순서로 배우나

> 이 연재를 끝까지 따라 하면 무엇을 할 수 있게 되는가?

실제 저장소에서 Rust 코드를 읽고, 고치고, 새 도구를 만들 수 있게 됩니다. 컴파일러가 내는 소유권·빌림·수명 오류를 읽고 왜 막혔는지 설명할 수 있게 됩니다. 에러 타입과 테스트를 설계하고, 성능과 크기를 직접 재서 판단하게 됩니다. 기술 면접에서 자주 나오는 Rust 주제(소유권, 트레이트와 디스패치, 동시성, async, unsafe)에 근거를 들어 답할 수 있게 됩니다.

할 수 없는 것도 적습니다. 이 연재만으로 입사가 보장되지는 않습니다. 면접은 언어 지식 말고도 자료구조·알고리즘, 시스템 설계, 협업 경험을 봅니다. 임베디드(`no_std`), WebAssembly, GUI, 게임 엔진은 다루지 않습니다. 웹 프레임워크는 async 편에서 쓰는 만큼만 다룹니다.

## 공부하는 법

- 글의 코드는 전부 저자가 돌려 본 것입니다. 기준은 rustc 1.100.0, cargo 1.100.0, 에디션 2024, Apple M4 Pro 14코어 macOS 입니다(2026-11-18).
- 코드를 읽기만 하지 말고 직접 쳐서 돌립니다. 컴파일 오류가 나오는 예시는 일부러 틀린 코드입니다. 오류를 직접 보고 고쳐 봅니다.
- 편마다 끝에 연습 2~3개와 풀이가 있습니다. 풀이를 열기 전에 먼저 풉니다.
- "면접에서 이렇게 묻는다" 절은 모범 답안의 요지만 적습니다. 자기 말로 30초 안에 설명할 수 있을 때까지 연습합니다.
- "한 단계 더" 절은 내부 동작과 트레이드오프(맞바꾸는 것)를 다룹니다. 처음 읽을 때는 건너뛰어도 됩니다.
- 예시는 저자가 운영하는 문서 변환 엔진(Rust 약 5만 줄, `unsafe` 0줄)의 실제 패턴을 줄여서 씁니다.

## 1단계 입문 — 혼자서 작은 도구를 만든다

| 편 | 제목 | 한 줄 목표 | 선수 편 | 면접 주제 |
|---|---|---|---|---|
| 1 | 설치부터 첫 실행 파일까지 | rustup·cargo 로 만들고, 고치고, 검사하고, 릴리스 빌드한다 | 없음 | 디버그와 릴리스 빌드의 차이, 정수 오버플로, `Cargo.lock` 을 커밋하는가 |
| 2 | 소유권 — 값의 주인은 하나다 | 이동·복사·복제를 구별하고 `String` 과 `&str` 을 골라 쓴다 | 1 | 이동과 복사, `Copy` 와 `Clone`, `String` 과 `&str`, 스택과 힙 |
| 3 | 빌림과 수명 첫걸음 | `&`·`&mut` 규칙과 수명 표기를 이해하고 빌림 오류를 고친다 | 2 | 공유 XOR 가변 규칙, 댕글링 참조, 수명 표기의 뜻 |
| 4 | 타입으로 설계하기 | 구조체·`enum`·패턴 매칭·`Option`/`Result`·`?`·트레이트로 상태와 실패를 타입에 담는다 | 3 | `enum` 과 패턴 매칭의 완전성, `?` 의 변환, `thiserror`, 트레이트 객체 기초 |
| 5 | 실전: 파일을 뜯는 파서와 CLI | 바이트를 안전하게 읽고 이터레이터·`clap`·테스트·`rayon` 으로 도구를 완성한다 | 4 | 경계 검사, 이터레이터 구현, 병렬 처리에서 컴파일러가 막는 것 |

## 편마다 들어가는 것

1. 첫머리의 질문 하나와 답
2. 삽화 한 장. 주인공은 돋보기를 든 검수 로봇입니다
3. 본문. 컴파일러가 막는 것은 실제 오류 출력으로, 성능·크기·배치는 직접 돌린 실험으로 보입니다
4. 면접에서 이렇게 묻는다. 3~5문항과 모범 답안 요지
5. 연습 2~3개와 풀이
6. 한 단계 더. 내부 동작이나 트레이드오프

실험으로 보일 수 없는 내부 동작은 공식 문서(The Rust Programming Language, The Rust Reference, The Rustonomicon, 표준 라이브러리 문서)를 근거로 쓰고 그렇다고 밝힙니다. 에디션이나 버전에 따라 달라지는 것은 버전을 적습니다.
