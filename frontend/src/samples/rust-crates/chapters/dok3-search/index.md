# Crate dok3-search

## Overview

Search orchestration, ACL enforcement, and original/section access.

## Items

- `in_memory` — In-memory SearchPort and DocumentStorePort implementation for P0-3 vertical slice.
- `seed` — Built-in Korean sample documents and optional dok3search-design loader.
- `service` — Application service layer for search, document reading, and readiness checks.
